Beginner Crochet Checklist

Use this checklist to make sure you have the basics you need before starting your first crochet project.

Supplies

  • ☐ Crochet hook
  • ☐ Yarn
  • ☐ Scissors
  • ☐ Yarn needle
  • ☐ Stitch markers

Skills to Practice

  • ☐ Make a slip knot
  • ☐ Hold the crochet hook comfortably
  • ☐ Make a chain
  • ☐ Make a slip stitch
  • ☐ Make a single crochet
  • ☐ Make a half double crochet
  • ☐ Make a double crochet

Before Starting a Project

  • ☐ Read the pattern or instructions
  • ☐ Check the yarn and hook requirements
  • ☐ Make a small practice sample
  • ☐ Find a comfortable place to crochet
  • ☐ Take your time and enjoy the process!

Ready?

Once you've checked off the basics, choose a simple project and start creating!
